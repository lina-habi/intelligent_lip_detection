# Intelligent Lip Detection and Movement Analysis in Video Sequences Using Deep Learning

## Project Description

This project aims to develop a computer vision system that detects lips in video sequences, analyzes lip movements, and studies their changes over time using deep learning and image processing techniques.

## Objectives

- Detect faces in video sequences.
- Locate the lip region.
- Extract and track lip landmarks.
- Perform lip segmentation.
- Analyze lip movement over time.
- Evaluate the developed methods.

## Project Workflow

Video Input → Face Detection → Lip Detection → Lip Segmentation → Movement Analysis → Results
